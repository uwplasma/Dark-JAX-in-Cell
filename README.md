**A classical massive-vector companion to [JAX-in-Cell](https://github.com/uwplasma/JAX-in-Cell).** It advances ordinary and dark fields with the same charged particles in periodic 1D3V PIC. The parent supplies particle loading, current deposition, field gathering, Boris pushing, ordinary Maxwell evolution and diagnostics; this package adds the Proca field, its potentials, coupling, energy and restart.

## Model

The canonical dark current coupling is $\eta$ and its rest frequency is $\Omega_D$ (rad/s). The explicit field step evolves

$$
\partial_t\mathbf E_D=c^2\nabla\!\times\!\mathbf B_D+\Omega_D^2\mathbf A_D-\eta\mathbf J/\epsilon_0,\qquad
\partial_t\mathbf B_D=-\nabla\!\times\!\mathbf E_D,\qquad
\nabla\!\cdot\!\mathbf E_D+\Omega_D^2\phi_D/c^2=\eta\rho_{\rm total}/\epsilon_0.
$$

Particles feel $q[\mathbf E+\eta\mathbf E_D+\mathbf v\times(\mathbf B+\eta\mathbf B_D)]$. Ordinary and dark Gauss laws use the **same fixed neutralizing background**; the physical mean current remains in both Ampère updates. The dark energy includes $|\mathbf E_D|^2+c^2|\mathbf B_D|^2+\Omega_D^2(|\mathbf A_D|^2+\phi_D^2/c^2)$, so a prescribed sinusoidal force is explicitly a separate **external-drive mode**, with work instead of dark-reservoir energy. [Equations, units and staggering](docs/physics.md) give the full model.

## Features

- Longitudinal and both transverse Proca polarizations, compatible Yee operators, full field/potential energy and both Gauss constraints.
- End-to-end JAX derivatives through loading, particle weights, fields, dynamics and physical objectives.
- Full native restart; TOML and CLI runs; a separate prescribed-drive control with accumulated work.
- Constrained plasma-profile conversion with an outgoing photon-flux objective and held-out replay.

## What the examples establish

| Full example | Result | Independent comparison |
|---|---|---|
| [Cold exchange](examples/dark_photon.py) | Max mean-field error **2.922×10⁻⁴** over the initial dark field; closed-energy drift **8.705×10⁻⁵** through $\omega_0t=20$ | Cold four-state matrix exponential; [run record](docs/_static/figures/cold_exchange/run.json) |
| [Mixed kinetic mode](examples/dark_kinetic.py) | $\omega/\omega_p=1.43207-0.14576i$ from PIC | Landau-continued Vlasov–Proca root $1.43695-0.14186i$; [fit and limits](docs/kinetic.md) |
| [Density calibration](examples/optimize_dark_photon.py) | PIC optimum $\omega_p^2/\omega_0^2=1.0016225$ | Independent cold/Fréchet optimum **1.0016317**, finite differences and time refinement; [details](docs/optimization.md) |
| [Fixed-column slab](examples/dark_profile.py) | Held-out outgoing-photon fraction **0.0020826 → 0.0021179**; refined gain **1.81–1.82%** | Independent cold scattering, fixed-column/peak constraints and held-out PIC replay; [full record](docs/profile.md) |

The [examples](examples/) also check all three vacuum polarizations, oblique magnetized 3V response, current-neutral two-stream and transverse-anisotropy growth, a resonant external drive, and mobile-ion finite-reservoir controls. The slab's finite-amplitude replay changes the yield, but finds **no reliable extra advantage from re-optimizing** at high amplitude. These are bounded numerical checks, not a detector prediction or a reproduction of the long nonlinear heating curves in [Hook, Huang and Shalaby (2025)](https://arxiv.org/abs/2510.13956). [Validation and open limits](docs/validation.md) separate each measured result from unfinished reproduction work.

## Install and run

```sh
git clone https://github.com/uwplasma/Dark-JAX-in-Cell.git
cd Dark-JAX-in-Cell
python -m pip install -e '.[test]'
darkjaxincell examples/input.toml --steps 160 --save artifacts/cold_run
```

The [TOML input](examples/input.toml) uses JAX-in-Cell's `[domain]`, `[[species]]`, `[solver]` and `[run]` tables, then a final `[dark]` table. CLI `--steps`, `--seed`, `--eta` and `--omega` override the file; `--save` writes fields, a full restart, the input and provenance. The parent is pinned to reviewed `research-release` commit [`83d3271`](https://github.com/uwplasma/JAX-in-Cell/tree/83d327118163833f93e2588edcb5029241f6ba2a).

```python
from darkjaxincell import load_toml

sim, run = load_toml("examples/input.toml")
out = sim.run(**run)
print("🌘 dark Gauss residual:", abs(out.dark_gauss()).max())
print("🦇 total energy (J/m²):", out.energy()["total_with_dark"][-1])
```

Run a quick smoke case with `python examples/dark_photon.py --quick`. Regenerate **full** figures, numerical records and MyST substitutions with `python docs/scripts/make_all.py`; regenerate the README loops with `python docs/scripts/make_movies.py` after `python -m pip install -e '.[media]'`. Quick runs are not full validation. The supported solver is periodic, explicit, electromagnetic Ampère PIC without filters, collisions or particle sources.

## Context and credit

The homogeneous cold and kinetic limits above are independent checks of this implementation. Conversion in inhomogeneous plasma was studied by [Aramburo Garcia *et al.* (2020)](https://arxiv.org/abs/2003.10465); structured dark-photon conversion predates this code in [Baryakhtar, Huang and Lasenby (2018)](https://arxiv.org/abs/1803.11455) and the optimized multilayer experiment of [Manenti *et al.* (2022)](https://arxiv.org/abs/2110.10497). Our fixed-column kinetic slab is a numerical model with a different geometry and objective. The [physics](docs/physics.md), [profile](docs/profile.md) and [kinetic](docs/kinetic.md) pages give derivations, references and limits.
